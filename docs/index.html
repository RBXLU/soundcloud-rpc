How it works

Как это работает

Browsers on Linux already tell the system what they're playing. soundcloud-rpc just listens and forwards it to Discord.

Браузеры в Linux и так сообщают системе, что сейчас играет. soundcloud-rpc просто слушает и пересылает это в Discord.

01

BrowserБраузер

You play a track on soundcloud.com.

Вы включаете трек на soundcloud.com.

02

MPRIS / D-Bus

The browser publishes title, artist, position and page URL.

Браузер публикует название, исполнителя, позицию и адрес страницы.

03

soundcloud-rpc

Picks the SoundCloud player and fetches artwork via oEmbed.

Находит плеер SoundCloud и берёт обложку через oEmbed.

04

Discord

Gets the status over its local IPC socket.

Получает статус через локальный IPC-сокет.

What you get

Что умеет

Small on purpose. It does one thing and stays out of the way.

Маленький специально. Делает одно дело и не мешает.

Only while playing

Только пока играет

The status disappears a few seconds after you pause or close the tab.

Статус пропадает через пару секунд после паузы или закрытия вкладки.

Tracks and seeking

Смена трека и перемотка

Next track or a jump in the timeline is picked up automatically.

Следующий трек или прыжок по таймлайну подхватываются сами.

Reconnects itself

Сам переподключается

Restart Discord whenever you like, the script finds it again.

Перезапускайте Discord как угодно, скрипт найдёт его снова.

Real artwork

Настоящая обложка

Looked up through SoundCloud's public oEmbed, with a logo fallback and retries.

Берётся из открытого oEmbed SoundCloud, при ошибке будет логотип и повтор.

No tokens

Без токенов

Nothing logs into your account. Only a public Application ID is needed.

Ничего не входит в ваш аккаунт. Нужен только публичный Application ID.

Native, Flatpak, Snap

Обычный, Flatpak, Snap

Finds the Discord socket wherever your build keeps it.

Находит сокет Discord, где бы его ни держала ваша сборка.

  • Python 3 + python-dbus python-dbus (Arch) · python3-dbus (Debian, Ubuntu, Fedora)

Install

Установка

  1. Create a Discord application

    Создайте приложение Discord

    Its name is what the status says. Open the Developer Portal, click New Application, name it SoundCloud and copy the Application ID.

    Его название и будет в статусе. Откройте Developer Portal, нажмите New Application, назовите SoundCloud и скопируйте Application ID.

  2. Run the installer

    Запустите установщик

    No root needed. Without an argument it asks for the ID.

    Root не нужен. Если не указать ID, установщик спросит его сам.

    git clone https://github.com/RBXLU/soundcloud-rpc.git
cd soundcloud-rpc
./install.sh YOUR_APPLICATION_ID

  3. Play something

    Включите музыку

    Open soundcloud.com, hit play and check your Discord profile.

    Откройте soundcloud.com, нажмите play и загляните в свой профиль Discord.

Usage

Управление

It runs as a systemd user service and starts on login.

Работает как пользовательская служба systemd и запускается при входе.

systemctl --user status soundcloud-rpc    # is it running?
journalctl --user -u soundcloud-rpc -f    # live log
systemctl --user restart soundcloud-rpc   # restart
./uninstall.sh                            # remove (--purge also forgets the ID)

Troubleshooting

Если что-то не так

Most problems come down to a Discord setting.

Чаще всего всё упирается в настройку Discord.

Nothing appears in my statusСтатус не появляется

In Discord go to Settings → Activity Privacy and turn on Share your detected activities with others. Make sure the desktop app is running, not the web version.

В Discord откройте Настройки → Конфиденциальность активности и включите «Показывать обнаруженную активность». Проверьте, что запущено приложение, а не веб-версия.

I see the SoundCloud logo instead of the artworkВместо обложки логотип SoundCloud

The artwork lookup failed. The script retries every 30 seconds; the reason is in the log.

Обложку не удалось получить. Скрипт повторяет попытку каждые 30 секунд, причина есть в журнале.

The “Listen” button is missingНет кнопки «Слушать»

Discord hides activity buttons on your own profile. Other people see it.

Discord не показывает кнопки активности вам самим. Другие люди их видят.

It works in Firefox but not in ChromeВ Firefox работает, а в Chrome нет

Chromium-based browsers often don't send the page URL over MPRIS, so the script can't tell a SoundCloud tab from any other player.

Браузеры на Chromium часто не передают адрес страницы через MPRIS, и скрипт не может отличить вкладку SoundCloud от другого плеера.
